A discord app bot created by [[SYSTEM]] for [[SERVER 01]].

According to [[SYSTEM]], the name came from a different software program.

![[Different software named APP TRUSTED 02 (SERVER 01).png|350]]

It had a list of commands that you could input, which would change with various updates made by [[SYSTEM]]. Below is the most recent bot command help menu:
```
​No Category:  
app_help  
app_log_ore  
app_name  
generate_randomkey  
hello  
help Shows this message  
print_bob  
whoami_app  
  
Type $help command for more info on a command.  
You can also type $help category for more info on a category.
```
---
## Commands:

**$app_help**

Displays the old help menu:
```
old[=============[help menu]============
<HELP>!:app_help
<HELP>!:Back]
```

**$app_log_ore**

```

<OUTPRINT>!:(init-0039, [KWPE+03 WFUS+8])
```

**$app_name**

Displays the properties of APP TRUSTED 02:
```
TRUSTED APP-02  
Model:0.2.92  
Serveing:FROM: LINX-OS, Storage disk 03, connected via [ETHERNET] TO:[https://discord.gg]
```

**$generate_randomkey**

Used to randomly generate 99 keys for [[SYSTEM]] to brute force its way into the cargo container for [[The Transmitter]] (which was hidden by [[Travis]]).

**$hello**

Simply prints out the message "hello"

**$help**

Displays the command menu

**$print_bob**

Prints bob.
